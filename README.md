# Tablero · Segmentación turística y rutas óptimas (ML + AG)

Ejecutar en local:

    pip install -r requirements.txt
    streamlit run app.py

Páginas: Tablero gerencial (`app.py`), Planificador de rutas (AG en vivo), Modelos de ML, Datos y supuestos.
Los datos de `data/` salen de `resultados_modelos.zip` (Colab 2). `ga_rutas.py` es el mismo módulo del Colab 2.
Para desplegar en Streamlit Community Cloud: subir esta carpeta a GitHub y elegir `app.py` como archivo principal.
